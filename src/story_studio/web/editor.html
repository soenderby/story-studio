      Comments

      Your draft, safely saved

      Browser autosave: every edit is saved to this browser’s local storage. Reopen this same editor.html, at the same location, in the same browser/profile to continue. Private browsing, clearing browser data, moving the editor or changing browsers can lose access to that copy. It is not a Dropbox backup.

      Recommended: open your story from the Story Studio app, which saves to story-project.json in the story’s folder automatically. Without it, “Link autosave file…” (Chrome / Edge) writes changes to a JSON project file you choose. To resume after reopening, use “Open project…” on that file again. Do not edit the same project in multiple tabs or computers at once.

      Portable backup: “Download backup” downloads a JSON copy containing chapters, text, captions, image order, image descriptions and private notes. Use “Open project…” to restore it.

      Finished story: “Read” shows the current draft. “Export story HTML” downloads a read-only page with the pictures inside, so it works on its own. “Export PDF” downloads the same story as a PDF. Neither includes private notes or comments.

      Only top-level images and videos are listed. Your images and videos are never overwritten by the editor. ⋯ → Settings → “Hide all images and videos” replaces them with small placeholders everywhere.
